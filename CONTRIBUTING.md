# Contributing

Thanks for considering a contribution.

1. Keep changes focused and add tests for behavioral changes.
2. Run `mvn verify` with JDK 25 before opening a pull request.
3. Follow the existing Java style: immutable API objects, explicit null checks, and clear Javadoc
   on public APIs.
4. Do not introduce a dependency on a specific Spring Boot runtime version.
5. Open an issue for security sensitive topics instead of filing a public pull request.

By contributing, you agree that your contributions are licensed under the Apache License 2.0.
